# Code of Conduct

Hardwire follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/). In short: be welcoming, be respectful, assume good faith, and keep discussions about the work.

## Reporting

If you experience or witness unacceptable behaviour, report it privately to the maintainer, [@Kymr10n](https://github.com/Kymr10n), through the repository's [private vulnerability report form](https://github.com/Kymr10n/hardwire/security/advisories/new) (it reaches only the maintainer, whatever the topic). Reports are handled confidentially. The maintainer may remove comments, commits or issues that break this code, and may block repeat offenders, following the Covenant's enforcement guidelines.
