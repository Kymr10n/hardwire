# Security policy

Hardwire is an offline, single-player game: no accounts, no network code, no server. It writes one file, its save, into the platform's user data directory. A bug that lets a crafted save or a hosted web build do something harmful is still worth reporting.

## Supported versions

Only the latest release on the [releases page](https://github.com/Kymr10n/hardwire/releases) receives fixes.

## Reporting a vulnerability

Please do not open a public issue. Use GitHub's private form: [Report a vulnerability](https://github.com/Kymr10n/hardwire/security/advisories/new). Include the version, the platform and the steps to reproduce.

You will get a reply within 14 days. There is no bug bounty.
